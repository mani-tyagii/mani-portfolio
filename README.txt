MANI TYAGI — PORTFOLIO WEBSITE

FILES
- index.html: page structure and content
- style.css: dark responsive design
- script.js: mobile menu, scroll reveal and active navigation
- images/profile-placeholder.svg: temporary profile image placeholder

HOW TO RUN
1. Extract this ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.

ADD YOUR OWN PROFILE PHOTO
1. Put your photo in the images folder and name it profile.jpg.
2. In index.html, find:
   src="images/profile-placeholder.svg"
3. Change it to:
   src="images/profile.jpg"

BEFORE SUBMISSION
- Replace the LinkedIn placeholder URL with your actual profile URL.
- Check that the email address is correct and that you want it public.
- Update the education details if you want to show school name/year.
- Replace the sample/coming-soon project card with your actual completed project.
- Add only skills you can comfortably discuss.
- Test the site on desktop and mobile.

GITHUB
Create a PUBLIC repository named mani-portfolio and upload the contents of this folder
(index.html, style.css, script.js, images folder and README.txt).
